# Clean-room rules

The canonical rules are [in the wiki](../../docs/contribution/clean-room.md).
Read that page before acting on anything that touches the protocol or the API.
It is the only copy of the source list, deliberately.

The short version, which does not replace reading the page:

- Build only from the sources that page permits.
- Never run, download, observe, or benchmark the proprietary server, for any
  reason, including testing.
- Cite the source of every protocol or API fact, or prove it with a test.
- When a fact is only available from a forbidden source, stop and say so.
